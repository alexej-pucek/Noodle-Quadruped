# Noodle-Quadruped
A custom built 12-DOF four legged open source Quadruped Robot with LiDAR, SLAM and Nav2. Uses ESP32 for low level control, and Intel NUC for high level brain running ROS2 on Ubuntu. This project is still under development.


![](gallery/photo1.png)

## Key Features

-**ROS2 High Level Control** - SLAM, Nav2, Lidar Data Parsing running on IntelNUC on ROS2 Jazzy.
-**Perception** - Noodle is equipped with LDS02RR LiDAR for precise positioning and navigation.
-**Embedded Control** - Low level brain ESP32 for calculating IK, walking gaits, IMU based stabilization and Servo control.
-**Power Distribution** - Powered from 2 Batteries, one for Servos and ESP32,other for Intel NUC.
